LAB 02 — Teacher-led Guide

ใช้ Notepad และ Browser พิมพ์ทีละขั้นในไฟล์เดิม ยกเว้น Debugging Mission ให้แยกไฟล์ ครูตรวจโค้ดก่อนเปิดใน Browser

Chapter 1

Hello Browser • 3 นาที

พิมพ์ข้อความลงใน Editor ที่ว่างอยู่

Hello World!

ทำไมข้อความแสดงได้ทั้งที่ยังไม่มีแท็ก? ลองเลือก Structure

HTML • 4 นาที

ครอบข้อความเดิมด้วย html แท็กเปิดและปิด

<html>
Hello World!
</html>

ผลหน้าเว็บเปลี่ยนไหม? ดูโครงสร้าง

HEAD • 3 นาที

เพิ่ม head ภายใน html ก่อนข้อความเดิม

<head>
</head>

head อยู่ภายใน html; body ยังถูกสร้างโดยเบราว์เซอร์

TITLE • 4 นาที

เพิ่ม title ภายใน head แล้วเปลี่ยนเป็นชื่อเว็บของตน

<title>My Website</title>

ชื่อแท็บจำลองเปลี่ยน แต่เนื้อหาหน้าเว็บเปลี่ยนไหม?

BODY • 4 นาที

ครอบข้อความที่ต้องการแสดงด้วย body หลัง head

<body>
Hello World!
</body>

ลองเปลี่ยน title และ body ทีละส่วน

DOCTYPE • 2 นาที

เพิ่ม DOCTYPE ที่บรรทัดแรก ไม่ใช่แท็กคู่

<!DOCTYPE html>

ดู Document mode ก่อนและหลังเพิ่ม DOCTYPE

META • 3 นาที

เพิ่ม meta charset ก่อน title ใน head; meta ไม่มีแท็กปิด

<meta charset="UTF-8">

UTF-8 ช่วยระบุการเข้ารหัส; การลบ meta ไม่ได้ทำให้ภาษาไทยเสียเสมอ

Skeleton Mission • 7 นาที

ปรับชื่อเว็บและข้อความต้อนรับตามงาน Week 01

<title>My Gaming World</title>

ตรวจชื่อแท็บและข้อความของตนเอง

Chapter 2

Plain Text • 3 นาที

เพิ่มชื่อเว็บ ข้อความต้อนรับ About Me และงานอดิเรกเป็นหลายบรรทัดใน body

My Gaming World
ยินดีต้อนรับ
About Me
ฉันชอบเล่นเกม

ทำไม Enter ไม่ขึ้นบรรทัดใหม่ตามที่พิมพ์?

H1 • 3 นาที

ครอบชื่อเว็บด้วย h1 ซึ่งเป็นหัวข้อหลัก

<h1>My Gaming World</h1>

h1 มีความหมายเป็นหัวข้อหลัก ไม่ใช่แค่ตัวใหญ่

H2 • 3 นาที

ครอบ About Me ด้วย h2 ซึ่งเป็นหัวข้อรอง

<h2>About Me</h2>

h2 เป็นหัวข้อรอง ไม่ต้องซ้อนใน h1

Paragraph • 3 นาที

ครอบข้อความต้อนรับและงานอดิเรกด้วย p แยกกัน

<p>ยินดีต้อนรับ</p>

ย่อหน้าต่างจากการกด Enter อย่างไร?

Content Hierarchy • 3 นาที

จำแนกเนื้อหาห้ารายการด้านล่าง

h1 / h2 / p

เลือกตามความหมาย ไม่ใช่ขนาดตัวอักษร

Tell Your Story • 5 นาที

ปรับเนื้อหาให้ตรงกับเว็บไซต์ Week 01 ของตน

<h2>About Me</h2>
<p>ฉันชอบเล่นเกม</p>

เนื้อหาสื่อถึงเว็บไซต์ของเราไหม?

Chapter 3

Text or Image? • 2 นาที

เพิ่มชื่อไฟล์ในย่อหน้า

<p>cat.jpg</p>

ชื่อไฟล์เป็นข้อความ ไม่ใช่ภาพ

Meet the Image Tag • 4 นาที

คัดลอก URL จาก Image Library แล้วพิมพ์ img เอง

<img src="URL">

src ระบุแหล่งรูป; img ไม่มีแท็กปิด

Missing Image • 3 นาที

ลองพิมพ์ URL ผิด สังเกต แล้วแก้กลับ

<img src="wrong.jpg">

ทำไมรูปไม่แสดง?

Give Images a Voice • 3 นาที

เพิ่ม alt ที่อธิบายรูป

<img src="URL" alt="แมวสีส้ม">

alt เป็นข้อความทดแทน ไม่ใช่คำบรรยายใต้ภาพ

Local Image • 5 นาที

เลือกภาพจาก Library คัดลอก Relative Path แล้วพิมพ์ img

<img src="images/cat.jpg" alt="แมวสีส้ม">

index.html อยู่ข้างโฟลเดอร์ images; ลอง cat.jpg เทียบกับ ./images/cat.jpg

Size & Symbols • 3 นาที

เพิ่ม width ให้รูปและ emoji ในข้อความ

<img src="images/cat.jpg" alt="แมวสีส้ม" width="200">
<p>🐱</p>

width เป็นพิกเซล ไม่ใช่ขนาดไฟล์; emoji เป็นข้อความ

Make It Yours • 5 นาที

เลือกภาพและ emoji ให้เหมาะกับเว็บไซต์

<img src="images/game.jpg" alt="จอยเกม" width="200">

ภาพสื่อความหมายตรงกับเว็บหรือไม่?

Chapter 4

Silent Button • 3 นาที

เพิ่ม button แล้วลองกด

<button>Click Me!</button>

ปุ่มยังไม่มีคำสั่งเฉพาะเมื่อไม่มี JavaScript; ใน form อาจมีพฤติกรรมเริ่มต้น

Magic Link • 4 นาที

เพิ่มลิงก์ไป Google

<a href="https://www.google.com">Go to Google</a>

href ระบุปลายทาง; ในระบบนี้ปิดการนำทางจริงเพื่อความปลอดภัย

Destination Detective • 3 นาที

เปลี่ยน href เป็น Wikipedia โดยคงข้อความเดิม ลองลบ href แล้วใส่กลับ

<a href="https://www.wikipedia.org">My Favorite Website</a>

ข้อความกับปลายทางเป็นคนละสิ่ง

Button or Link? • 2 นาที

จำแนกสถานการณ์สี่รายการ

button / a

ใช้ a สำหรับนำทาง ใช้ button สำหรับการกระทำ

Make It Clickable • 3 นาที

เพิ่มปุ่มและลิงก์ที่เกี่ยวข้องกับเว็บของตน

<button>Start Game</button>
<a href="https://www.minecraft.net">Visit Minecraft</a>

ปุ่มเป็นตัวอย่าง ยังไม่มีคำสั่งเฉพาะ

Chapter 5

Broken Website • 4 นาที

แก้บั๊กสามจุดใน Debug Editor แยก: หัวข้อ รูป ลิงก์

<h1>🐱 My Lovely Cat</h2>
<img src="images/catt.jpg" alt="แมวสีส้ม" width="200">
<a>Learn More About Cats</a>

เป้าหมาย: หัวข้อ h1, images/cat.jpg และ https://en.wikipedia.org/wiki/Cat

Final Challenge

1. เปลี่ยนชื่อแท็บโดยไม่เปลี่ยนหัวข้อหน้าเว็บ แก้แท็กใด?
  1. h1
  2. title
  3. body
  4. p
2. ทำไม Hello World! แสดงได้โดยไม่มีโครงสร้าง HTML?
  1. เป็น JavaScript
  2. ไม่ต้องใช้ HTML เลย
  3. เบราว์เซอร์สร้างโครงสร้างที่ขาด
  4. เป็นรูปภาพ
3. meta charset UTF-8 ทำหน้าที่อะไร?
  1. ระบุการเข้ารหัสอักขระ
  2. กำหนดสี
  3. สร้างหัวข้อ
  4. กำหนดลิงก์
4. หัวข้อหลัก หัวข้อรอง รายละเอียด ใช้แท็กใดตามลำดับ?
  1. p,h1,h2
  2. h2,p,h1
  3. h1,p,h2
  4. h1,h2,p
5. Hello และ World อยู่คนละบรรทัดใน body ปกติจะแสดงอย่างไร?
  1. แยกย่อหน้าเสมอ
  2. ช่องว่างถูกยุบ
  3. ไม่แสดง
  4. กลายเป็นหัวข้อ
6. cat.jpg อยู่ใน images ข้าง index.html ต้องใช้ src ใด?
  1. images/cat.jpg
  2. cat.jpg
  3. image/cat.jpg
  4. index.html/cat.jpg
7. alt ใช้ทำอะไร?
  1. กำหนดขนาด
  2. กำหนดสี
  3. สร้างลิงก์
  4. ข้อความทดแทนรูป
8. แท็กใดสร้างลิงก์ไป Google โดยไม่ใช้ JS?
  1. <button>Google</button>
  2. <a>Google</a>
  3. <a href="https://www.google.com">Google</a>
  4. <p>Google</p>
9. เปลี่ยนปลายทางลิงก์โดยไม่เปลี่ยนข้อความ แก้อะไร?
  1. href
  2. alt
  3. width
  4. title
10. ข้อผิดพลาดของ <h1>My Website</h2> คืออะไร?
  1. ไม่มีรูป
  2. แท็กปิดไม่ตรงแท็กเปิด
  3. ชื่อเว็บสั้น
  4. ไม่มี emoji
